同步学习记录

在手机和电脑用同一个加密口令，点击「合并并同步」。两台设备的高亮、话术卡改写和自测进度会合并，取消高亮也会同步。

只上传加密记录。访问令牌仅用于本次向 GitHub 提交，口令不上传，两者均不保存。请使用至少 16 个字符的独立口令并妥善保管。

首次设置：创建 GitHub 访问令牌

在 GitHub 创建细粒度令牌，选择 仅 english-board，仓库权限 Contents：Read and write。设置合理有效期。把令牌填在此处即可，不要发送到聊天。

资料管理

发布到 GitHub 后，所有设备看到同一份资料。这里只发布讲稿、分类和话术卡，不发布个人标记或练习记录。
